# personal-website

My personal portfolio — built with a glitchcore aesthetic: dark, minimal, and sharp.

## Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS v4**

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deployed on [Vercel](https://vercel.com). Push to `main` triggers automatic deploy.
